# Fonts

Latin subsets downloaded from Google Fonts and self-hosted so builds never fetch fonts over the network.
All are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/).
The files match those in FFC-EX-theeverythingproject.org.

| File                               | Family               |
| ---------------------------------- | -------------------- |
| `open-sans-400-800.woff2`          | Open Sans (variable) |
| `lato-400.woff2`, `lato-700.woff2` | Lato                 |
| `faustina-400-700.woff2`           | Faustina (variable)  |
